# nim-ts-mode
Nim tree sitter mode generated by AI. Use with [this](https://github.com/alaviss/tree-sitter-nim).

# Indentation
- `tab` is indent
- `backtab` is dedent

# Example
If you want to use with `eglot` and [nimlangserver](https://github.com/nim-lang/langserver):
```elisp
(add-to-list
 'treesit-language-source-alist
 '(nim "https://github.com/alaviss/tree-sitter-nim"))

(unless (treesit-language-available-p 'nim)
  (treesit-install-language-grammar 'nim))

(use-package nim-ts-mode
  :vc (:url "https://github.com/oddman621/nim-ts-mode"
       :rev :newest))
  :hook (nim-ts-mode . eglot-ensure))

(use-package eglot
  :ensure nil
  :config
  (add-to-list 'eglot-server-programs
               '(nim-ts-mode . ("nimlangserver"))))
```
